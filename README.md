# Phone Catalog

A feature-rich e-commerce web application for browsing phones, tablets, and accessories. It includes a dynamic shopping cart, favorites management, search, filtering, sorting, pagination, and persistent state using `localStorage`.

To get a local copy up and running, follow these simple steps.

## Installation
Clone the repository:
git clone https://github.com/your-username/phone_catalog.git
cd phone_catalog

Install dependencies:
npm install
 or
yarn install

Run the project locally:
npm start
 or
yarn start

## Features
The application features a modular architecture utilizing CSS Modules for styling, a sticky header with search, and a footer featuring a smooth back-to-top button and a GitHub link. Users can explore a Home page with automated image sliders, hot prices, brand new products, and category links. The dedicated catalog pages for phones, tablets, and accessories offer sorting options, customizable pagination, and search queries saved directly in URL parameters. The product details page displays comprehensive specs, color and capacity options, image galleries, and a "You may also like" recommendation block. Both the shopping cart and favorites systems feature automatic calculations, interactive quantity controls, and state persistence using local storage, complete with a checkout confirmation modal and interactive wishlist buttons.
